Autogenerated op reference for the **CHLO (Client HLO) dialect** — higher-level, frontend-friendly ops that legalize *down* to StableHLO (via [`-chlo-legalize-to-stablehlo`](generated-stablehlo_passes.md)). Under the reference lens: CHLO ops (`chlo.broadcast_add`, `chlo.erf`, `chlo.asin`, …) are what you see *before* legalization; they carry implicit-broadcasting semantics and transcendental/special functions that StableHLO decomposes.

## Key points

- **[CHLO dialect](src:docs/generated/chlo.md#chlo-dialect)** groups two big families: implicitly-broadcasting binary elementwise ops (`chlo.broadcast_add` [chlobroadcast_add-chlobroadcastaddop](src:docs/generated/chlo.md#chlobroadcast_add-chlobroadcastaddop), `broadcast_divide`, `broadcast_compare`, …) and special math (`chlo.acos` [chloacos-chloacosop](src:docs/generated/chlo.md#chloacos-chloacosop), `asin`, `atan`, `bessel_i1e`, etc.).
- The quant-to-math lowering introduces `chlo.broadcast_*` ops for scale/zero-point arithmetic (see [quantization.md](quantization.md)).
- See [attributes](src:docs/generated/chlo.md#attributes) and [cases](src:docs/generated/chlo.md#cases).
