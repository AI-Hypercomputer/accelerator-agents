Autogenerated (mlir-tblgen) catalog of the **transformation / legalization passes** in the StableHLO dialect. Under the reference lens: this is the pass-name dictionary for compiler-log lines — legalization to/from CHLO, VHLO, and quantized forms; shape-refinement passes that turn dynamic programs static; and compatibility expanders. Each pass here is a named `-stablehlo-…` / `-vhlo-…` / `-chlo-…` flag.
