# training/archive/README.md

A short deprecation notice: the PyTorch/XLA recipes under `training/archive/` are kept for reference
only and are no longer maintained. The repo's actively-maintained, fully-supported path for training
on TPU is the MaxText-based recipes in the main `training/` directory
([-archived-pytorchxla-recipes](src:training/archive/README.md#-archived-pytorchxla-recipes)).
