# Trace viewer tool

The Trace Viewer renders the captured timeline of host and device events (the Perfetto-style trace) — the primary tool for inspecting what ran when and where time went.

## Key points
- The trace viewer visualizes the captured host+device event timeline; interface components and interacting with the timeline ([trace-viewer-interface-components](src:docs/trace_viewer.md#trace-viewer-interface-components))
- Navigate from the trace viewer to the HLO graph ([from-trace-viewer-to-hlo-graph](src:docs/trace_viewer.md#from-trace-viewer-to-hlo-graph))
